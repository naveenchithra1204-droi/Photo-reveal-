# A Little Happy Corner 🐾

A small static website with HTML, CSS, JavaScript, and the included photo.

## Run locally
Open `index.html` in a modern browser. Keep `style.css`, `script.js`, and the `images` folder in their current locations.

## Host with GitHub Pages
Upload all files and the `images` folder to a GitHub repository (keep `index.html` at the repository root), then enable GitHub Pages in the repository Settings → Pages.
